Vansh Saxena Portfolio

vansh-portfolio/
  index.html            page markup (sections, text, links)
  css/base.css          colors, reset, buttons, navbar
  css/sections.css      hero, about, stack, timeline, projects, contact
  css/components.css    background, marquees, stat cards, hover effects
  js/data.js            EDIT HERE: roles, skills, projects, badges, CV link
  js/background.js      dotted page + wireframe shapes following the mouse
  js/stats.js           live GitHub + LeetCode stats (falls back to values in index.html)
  js/cursor.js          color-inverting custom cursor (dot over images)
  js/main.js            typing, cube, scroll reveal, heatmaps, rendering
  assets/images/        vansh.jpg and project previews
  assets/Vansh_Saxena_CV.pdf   used by the Download CV button

Run: open index.html in a browser.
Host: drag the folder onto Vercel or Netlify, or push to GitHub Pages.
CV: replace assets/Vansh_Saxena_CV.pdf with a newer file of the same name.
Email is set in index.html (search vanshsaxena2007).
